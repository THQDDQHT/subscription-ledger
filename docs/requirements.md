# 订阅账本：第一版需求

日期：2026-09-08
状态：需求草案，尚未开发或部署。

## 目标

给单个用户使用的私人 Web 订阅账本。在手机和电脑上查看订了什么、近期哪些需要续费、预计周期支出。所有金额固定使用人民币（元），不提供币种选择或汇率换算。手动录入，不读取银行或邮箱，不自动取消或扣费。

## 页面与操作

1. 首页：按下次扣款/续费日期排序，显示未来 7 天及 30 天待处理项目；过期未处理项目单独标记。
2. 新增和编辑：名称、每期金额（人民币元）、周期（月付/季付/年付/自定义天数）、下次扣款或续费日期、自动续费开关、管理链接、备注。
3. 状态：使用中、准备取消、已取消续费、已结束。已取消续费可填写服务可用截止日，不再计入预计续费支出；准备取消仍计入。
4. 续费确认：用户点击“已续费”并确认实际续费日期和下一次日期后保存。日期到来不代表已扣费，系统不冒充银行确认。默认下一次日期按原计划递推；月底及闰年按目标月份最后有效日处理，并保留原始日期锚点。
5. 删除：需明确确认。
6. 统计：统一以人民币显示月度等效预算及未来 30 天预计续费支出。月度等效不是实际账单；季付折算为每期金额/3，年付折算为每期金额/12，自定义天数使用每期金额×365/周期天数/12。金额使用十进制定点处理，统一显示人民币元。未来窗口按预计日期展开周期，不只数每条记录一次。取消/结束记录排除。
7. 备份：导出 JSON；支持校验后的 JSON 恢复，恢复覆盖前必须确认并备份旧数据。导出不包含登录秘密。

### 本次增补

- 移除页头“私人 · 人民币 ONLY”，保留人民币金额说明。
- 季付 `quarterly` 为三个日历月而非 90 天；月底夹取保留原日锚点，闰年与跨年一致；预测快进不得改变季度月份相位。
- 桌面列表主区、近期续费侧区，手机单列；强化统计数值层级，备份区可折叠。
- 原创本地 SVG favicon，遵循现有 `img-src self` CSP，不加载第三方资源。
- JSON version=1 向后读取兼容，季付导出恢复保留日期锚点。

## 隐私与部署

- 单用户密码登录，无注册、团队、OAuth 或会员功能。
- 服务端 SQLite 持久化，跨设备共用数据，不仅存浏览器 localStorage。
- 密码安全哈希、登录限速、HttpOnly 会话、写操作 CSRF 防护、链接仅接受 http/https。
- 默认日期按 Asia/Shanghai 解释，日期采用 YYYY-MM-DD，避免浏览器时区导致偏移。
- 移动端优先的中文界面；无第三方分析或遥测；不保存服务账号密码/API Key。
- 轻量后端 + SQLite + 原生 HTML/CSS/JS；提供 Docker 启动配置和持久化数据卷。
- 开发和隔离测试在 workspace 内进行，不改现有生产服务。
- 正式部署需要先明确宿主机端口/域名、影响和回滚方案，用户批准后再修改 Nginx 或启动生产服务。默认复用用户现有 Nginx，不另占 80/443。

## 不包含

Telegram/邮件主动提醒（第二阶段）；银行/邮箱同步；自动扣费或自动取消；实时汇率；发票账务；AI；试用转付费的自动状态机；多用户。

## 验收

- 创建、编辑、状态切换、续费确认、删除能持久化；刷新或重启后仍在。
- 未登录无法读取/修改私人数据；错误密码、CSRF、非法链接与非法金额有测试。
- 月底、闰年、过期日期、状态排除、跨周期统计、人民币金额精度有自动化测试。
- 备份可恢复，损坏导入不破坏现有数据。
- 手机宽度下可完成主要操作。
- 仅在真实运行和检查后报告可用，未接入公网前不声称已上线。
