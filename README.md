# 私人订阅账本

单用户中文手机 Web，Next.js（App Router）+ TypeScript + Tailwind + SQLite。**所有金额固定人民币**。手动录入，不接银行、邮箱，不自动扣款或取消订阅，无分析遥测。

## 当前交付边界

源码及隔离验收，不是公网部署；未配置 Nginx、域名或常驻服务。Docker 配置已提供但未实际构建/启动。手机响应式样式已实现，真实手机浏览器验收仍需完成。正式上线前须批准端口、域名、HTTPS、数据目录和回滚方案。

## 本机运行（Node 24+，pnpm）

```sh
pnpm install               # 安装依赖
pnpm init-password         # 首次设置登录密码，交互输入
pnpm dev                   # 开发模式，默认 http://127.0.0.1:8765，Ctrl-C 停止
```

生产方式：

```sh
pnpm build                 # 产出 .next/standalone
pnpm serve                 # 等价于 node .next/standalone/server.js，需先 build
```

`PORT=9000 pnpm dev`（或 serve）可换端口。Node 版本以 `packageManager` 字段与 Dockerfile 为准（Node 24 / pnpm 11）。**注意**：pnpm 11 的构建脚本白名单写在 `pnpm-workspace.yaml` 的 `allowBuilds`（不是旧的 `onlyBuiltDependencies`）。

## 从 Python 版升级

2026-09 重写为全栈 TypeScript（原 Flask 版已移除）。**现有 `data/` 目录直接沿用**：SQLite 库结构不变，werkzeug scrypt 密码哈希可直接验证（兼容 scrypt 与 pbkdf2 两种 werkzeug 格式），旧库缺少的续费金额/记录时间列仍自动补。两点一次性影响：旧会话 Cookie 全部失效（重新登录一次即可）；登录限速改为全局单桶（Node 路由层拿不到对端 IP，语义与原反代部署一致）。Docker 运行时从 Python 换为 Node。

## 数据与安全

默认数据目录为项目下 `data/`，可用 `LEDGER_DATA_DIR` 指定专用绝对路径；目录 0700，数据库、密码哈希及会话密钥 0600。不要把数据目录提交版本库。密码 12–1024 字符，以 scrypt 哈希存储（`pnpm init-password` 设置/更换，更换后请重启进程使旧会话失效）。密码不包含在 JSON 备份内。

`LEDGER_COOKIE_SECURE=1` 用于 HTTPS 部署；默认 0 仅为了 loopback HTTP 测试。不得把明文 HTTP 服务直接暴露公网。会话 Cookie 为 HMAC 签名（密钥在 `data/session.key`），HttpOnly、SameSite=Strict，12 小时有效；写请求校验 `X-CSRF-Token`。错误登录 15 分钟内最多 5 次（全局单桶）。安全响应头（CSP nonce、`nosniff`、`DENY`、`no-referrer`、`no-store`）由 `src/proxy.ts` 统一设置；带哈希静态资源使用 immutable 缓存。

## 使用与统计口径

- 新增/编辑名称、人民币每期金额、月/季/年/自定义天数周期、计划日期、自动续费标识、管理链接、备注。
- 使用中、准备取消计入预算；已取消续费、已结束排除。取消标记不会替你在服务商取消，管理链接仅接受无凭证 http/https。
- “已续费”要求明确确认实际续费日、实付金额与下一次日期；不能以未来日期确认实际付款。不会随日期到来自动改账。实付金额默认取当前每期金额，可改为本次真实支付额；它只写入这条续费历史，不改订阅的每期金额，涨价请另行编辑订阅。
- 详情页列出续费历史（实际续费日、原计划 → 下次、实付金额、记录时间），最新在前，并给出实付合计；升级前记录的历史没有金额与时间，标为“未记录”且不计入合计，不用当前金额冒充。只有最近一次、且此后计划日期未被编辑过的续费可以撤销：撤销把计划日期退回该次续费前的原计划日并删除这条历史，不改金额、状态与日期锚点；续费后又手工编辑过日期的记录不能撤销，需直接编辑日期。
- 月底按目标月份最后有效日处理，保留原始日/月锚点；直接编辑计划日期或周期重置锚点，手工续费不重置。
- 日期按 Asia/Shanghai。窗口为 `[今天, 今天+7/30天)`，逾期单列；预计支出展开周期，不代表扣费已发生。
- 季付 `quarterly` 按三个日历月递推（不是 90 天），保留原始日锚点：1 月 31 日 → 4 月 30 日 → 7 月 31 日。月度等效为金额/3；年付为金额/12；天数周期为金额×365/天数/12；预算合计以整数有理数精确求和后四舍五入到分，不是实际账单。

## 界面

工作台为浅灰侧栏 + 纸面色工作区，侧栏依次为「近期处理 / 全部订阅 / 数据备份」，左下角是外观切换（跟随系统 / 浅色 / 深色，偏好存浏览器 localStorage）与退出登录；手机底栏同样三个视图，外观切换与退出登录放在备份页底部。近期页保留三项统计（未来 30 天预计续费、逾期未确认、月度等效预算），清单按逾期 / 7 天内 / 30 天内分组并显示组内每期金额小计；逾期与 7 天内的记录行内直接提供「记录续费」。全部页直接显示清单，工具栏固定、列表独立滚动，支持名称/备注搜索、状态筛选、组内排序与分组折叠（已取消、已结束默认折叠）。整行可点击打开详情；宽屏详情与列表并排，窄屏为模态。鼠标环境下行内「记录续费」在悬停、键盘聚焦或选中时才出现，触屏常显；表头与分组标题在滚动时吸顶。金额千分位显示且货币符号弱化，日期同时给出「逾期/还剩 N 天」和「9月8日 周二」读法，记录本身仍为 ISO 日期。首次加载超过 120ms 显示骨架行。快捷键：`/` 聚焦搜索，`N` 新增订阅，`Esc` 关闭详情。删除与恢复备份使用页面内确认弹窗并写明影响的记录数。URL hash 保留视图和选中记录，支持刷新及浏览器返回。所有图标与资源均在本地（lucide），深色模式默认随系统，也可手动指定。

## 备份、恢复与回滚

页面导出 JSON 包含订阅及续费历史（含实付金额 `amount_cents` 与记录时间 `recorded_at`，早期记录为 null），不包含登录密码/密钥。备份页分「导出备份」与「恢复备份」两张卡片：导出卡片显示条数、文件名与本浏览器的上次导出时间（localStorage 仅存时间戳）；恢复卡片为拖放区，选中文件后先在本地解析并显示订阅数、续费历史数与文件大小，格式不对会就地提示且不允许恢复，确认弹窗会写明将被替换的记录数，服务器仍做完整校验。`version=1` 格式不变。

恢复须明确确认，严格校验格式/version=1/CNY、金额、日期、锚点、ID 唯一性、历史引用以及历史的金额（分）与记录时间；最多 2000 条订阅、10000 条历史，请求体最大 2 MiB（包含 JSON 包装）。验证失败不改库。恢复前将旧数据库备份到 `data/backups/*.sqlite3`，随后在同一写锁下事务覆盖（better-sqlite3 的备份走独立只读连接）；写入失败回滚。

需从服务器旧库回滚时：先停止账本服务，保留当前 `ledger.sqlite3` 副本，再用指定备份替换数据目录的 `ledger.sqlite3`，确认属主及 0600 权限后重启。不要在服务运行中直接复制覆盖 SQLite 文件。JSON 恢复不更改登录密码或会话密钥。服务器完整迁移可在停止服务后备份整个专用数据目录；含秘密，不能公开分享。

## 自动验收

```sh
pnpm test                  # vitest：领域算法 + API 行为 + 前端纯逻辑（135 项）
pnpm build && pnpm smoke   # 真实 TCP HTTP 验收（9 组），需先 build
```

vitest 覆盖 CRUD、状态、金额、日期锚点、预测快进、错误密码、限速、CSRF、恢复校验/回滚/备份失败、历史日期快进，以及续费历史的实付金额、撤销规则、旧库迁移和旧备份兼容；前端用例覆盖分组日期边界、搜索/筛选/排序、金额/日期格式化、路由解析与会话失效清理。HTTP 烟测使用随机密码、临时库及随机 **127.0.0.1** 端口，执行真实 Cookie 登录、CRUD、月底/季付续费、实付金额与撤销、备份恢复、进程重启持久化和退出隔离；结束终止子进程并检查端口关闭，临时数据删除。均不替代真实浏览器测试。

## Docker

CI（`.github/workflows/ci.yml`）在 main 分支与 `v*` 标签上跑测试 + 生产构建 + HTTP 烟测，通过后构建并推送多架构镜像（linux/amd64、linux/arm64）到 `ghcr.io/thqddqht/subscription-ledger`。镜像本身未在本机构建验证，首次使用前先跑通 CI。

本机或服务器手动构建：`docker compose build`（compose 配置：非 root、只读根文件系统、命名卷 `ledger-data` 持久化 `/data`，主机端口仅 loopback，默认 8765）。首次启动用一次性容器设置密码：`docker compose run --rm ledger pnpm init-password`。HTTPS 场景配置 `LEDGER_COOKIE_SECURE=1` 并使用现有反向代理；无需另占 80/443。
